# Screenshot deliverable

A genuine screenshot of a successful GitHub Actions run can only be captured after the workflow has run in your GitHub repository.

1. Open your repository on GitHub.
2. Click **Actions** → **Python CI** → the newest run.
3. Confirm the run shows a green check mark and **Success**.
4. Open the `test` job so the test results are visible.
5. Press **Win + Shift + S** on Windows and select the browser area.
6. Save it as `successful-ci-run.png`.

Do not use a mock screenshot as proof of a real run.
